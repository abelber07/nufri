# IA a Nufri · Projecte DASP (RA1 + RA2)

Presentació web del projecte de digitalització amb intel·ligència artificial.
Grup: Mauri, Arnau, JoseMa i Abel · CFGS DAW · Curs 2026-2027

## Fitxers
- `index.html`: la presentació (HTML, CSS i JavaScript en un sol fitxer)
- `assets/`: memòria (PDF), pòster (PDF i imatge) i presentació (PowerPoint)

## Com es fa servir
- Fletxes del teclat o espai per avançar, o lliscar al mòbil
- Tecla `O`: índex de totes les diapositives
- Tecla `F`: pantalla completa

## Publicar-ho a GitHub Pages
1. Crear un repositori nou a GitHub.
2. Pujar-hi `index.html` i la carpeta `assets` (Add file > Upload files).
3. Anar a Settings > Pages, triar la branca `main` i la carpeta `/ (root)`, i desar.
4. En un parell de minuts la web estarà a `https://USUARI.github.io/NOM-DEL-REPO/`.
